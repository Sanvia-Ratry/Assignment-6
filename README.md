# DigiTools

## Description
This is an e-commerce website for digital AI tools and subscription packages.

## Technologies Used
* **JavaScript** (ES6+)
* **React**
* **Tailwind CSS**

## Key Features
* 🛒 **Product Add to Cart** – Add AI tools dynamically to your active shopping cart dashboard.
* ❌ **Product Remove from Cart** – Easily remove specific products from your selection list.
* 💳 **Checkout** – Process total prices and check out your final order instantly.
